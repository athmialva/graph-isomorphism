Definitions

Learn the essential vocabulary and ideas behind graphs and graph isomorphism.

Key terms
Vertices · Edges · Mapping
1

What is a graph?

A graph is a way of showing connections between objects. It consists of vertices (points) and edges (lines) that join some pairs of vertices.

Simple definition: a graph is a set of points with links between them.

Example: a triangle is a graph with 3 vertices and 3 edges, where each vertex is connected to two others.

2

What is graph isomorphism?

Two graphs are isomorphic when they have the same structure, even if they are drawn differently or their vertices are labelled differently.

In simple terms, one graph can be relabelled to match the other exactly.

Notation: if graphs G and H are isomorphic, we write G ≅ H.

3

Isomorphic graphs

Isomorphic graphs have the same number of vertices and edges, and the same pattern of connections.

If we can match each vertex in one graph to a vertex in the other, and every connection still matches, then the graphs are isomorphic.

Example: two squares drawn in different positions are still the same graph because they both have 4 vertices in a cycle.

4

Non-isomorphic graphs

Non-isomorphic graphs do not have the same structure. No matter how we rename the vertices, one graph cannot be turned into the other without changing its connections.

Example: a triangle and a path of 3 vertices are not isomorphic because the triangle has each vertex connected to two others, while the path has two end vertices with degree 1.

5

Vertex mapping / correspondence

A vertex mapping is a way of pairing each vertex in one graph with a vertex in another graph.

If a vertex u in graph G is matched with a vertex f(u) in graph H, then this gives a correspondence between the two graphs.

Simple idea: rename the vertices of one graph so they line up with the other graph.

Example: if graph G has vertices A, B, C and graph H has vertices 1, 2, 3, then a mapping could be A → 1, B → 2, C → 3.

6

Adjacency preservation

Adjacency preservation means that if two vertices are connected in one graph, their matched vertices are also connected in the other graph.

In symbols, if u and v are adjacent in G, then f(u) and f(v) are adjacent in H. The same is true for non-adjacent vertices.

Example: if A is connected to B in the first graph, then the matched vertices f(A) and f(B) must also be connected in the second graph.

Isomorphic Graphs

Both graphs have 4 vertices and 4 edges, and each vertex connects to the same pattern of neighbours after relabelling. Because we can match the structure exactly, the graphs are isomorphic.

Non-Isomorphic Graphs

These two graphs both have 4 vertices, but their connection patterns are not the same.

In Graph G, one vertex is connected to two others in a different way than in Graph H. No relabelling can make the edge connections match exactly, so they are not isomorphic.

Example 03

Same Number of Vertices and Edges, But Non-Isomorphic

Both graphs have 5 vertices and 5 edges, but the pattern of connections is different.

In Graph G, the shape is a cycle with one extra connection, while in Graph H, the edges form a different arrangement. Since the connectivity differs, there is no valid one-to-one mapping that preserves all adjacencies, so they are not isomorphic.
