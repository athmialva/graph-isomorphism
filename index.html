01 · The idea

What is Graph Isomorphism?

Two graphs are isomorphic when they have the same connections, even if their drawings or vertex names look different.

Think of it as renaming the vertices without changing the shape.

Same structure means the same pairs are connected. Names, positions, and even the way we draw the graph can change.

02 · The check

How do we find it?

  1. 1Check that both graphs have the same number of vertices.
  2. 2Check that both graphs have the same number of edges.
  3. 3Compare vertex degrees: count how many edges touch each vertex.
  4. 4Match vertices while keeping every connection the same.

These checks narrow it down; a valid matching that preserves every connection confirms the graphs are isomorphic.

Basic Graph Terms

Vertex: A vertex is a point or node in a graph.

Edge: An edge is a line that connects two vertices.

Degree of a Vertex: The degree of a vertex is the number of edges connected to that vertex.

Example: If 3 edges are connected to A1, then Degree(A1) = 3.
